## 三、可复现性索引

所有结论都能回到版本、运行编号和原始记录：

| 材料 | 位置 |
|------|------|
| Agent 版本快照 | `GET /api/version`（agent_version / prompt_version / kb_version / git 提交号） |
| 运行日志（七类字段、脱敏） | `logs/runs.jsonl`，可用 `GET /api/runs/{run_id}` 查询 |
| 统一测试集输入（冻结） | `tests/common/unified.py` |
| 组内回归测试 | `tests/custom/project_tests.py` |
| 测试原始结果（未筛选） | `tests/reports/*.json` 与 `*.md` |
| 测试运行器 | `python tests/run_tests.py --label <标签> --suite both` |

### 重新生成全部交付物

```bash
# 1. 启动服务（另开终端）
uvicorn main:app --port 8000

# 2. 跑测试并生成自测试报告
python tests/run_tests.py --label V2 --suite both --base http://127.0.0.1:8000
python deliverables/build/generate_selftest.py

# 3. 生成 PPT 与文档
python deliverables/build/generate_pptx.py
python deliverables/build/build_all.py

# 4. 生成源码快照与个人总结
python deliverables/build/copy_source.py
python deliverables/build/generate_personal.py --names "姓名1,姓名2,姓名3"
```
